**新增**: `tools/chem_calc.py`

- `compute_descriptors(smiles)`: 分子式、分子量、LogP、原子数、环数、可旋转键、氢键供/受体

## Bug 修复: DeepSeek API tool_call 消息格式错误

**文件**: `agents/nodes.py`, `agents/graph.py`, `agents/state.py`

- **根因1**: 并行 Send fan-out 导致化学/文献专家的 tool_call 消息交错，DeepSeek API 要求 `AIMessage(tool_calls=...)` 紧随其后就是对应的 `ToolMessage`
- **根因2**: 测试与 Streamlit 共享 `local_data/checkpoints.db`，SqliteSaver 残留状态导致 `round_count` 超标
- **修复1**: `both` 路径从并行 Send 改为顺序链式（chem→lit），通过 `both_active` 状态字段跟踪
- **修复2**: 测试使用独立 DB (`CHEMASSIST_TEST_DB` 环境变量)
- **修复3**: `local_files_only=True` 使 SentenceTransformer 完全离线，不需 HuggingFace 验证

## 真实查询评估脚本

**新增**: `eval_agent.py`

- 11 个测试用例，覆盖基础化学/文献/组合/边界/单Agent 5 个维度
- 真实 DeepSeek API 调用，非 mock
- 评估指标：工具调用检查、关键词验证、禁止词检查

- combined-chem-lit 用例耗时 49.5s（顺序执行 chem + lit）

## 踩坑记录

| 问题 | 原因 | 解决 |
|------|------|------|
| Windows 终端 GBK 编码报 `UnicodeEncodeError` | emoji 和中文在 GBK 下无法编码 | `sys.stdout.reconfigure(encoding='utf-8')` + 全部用纯 ASCII |
| `MolecularFormula` 不存在 | RDKit 2026.3 API 变更 | 改用 `rdMolDescriptors.CalcMolFormula` |
| `SqliteSaver.from_conn_string()` 返回 GeneratorContextManager | 新 API 改为上下文管理器 | 改用 `sqlite3.connect()` + `SqliteSaver(conn)` |
| `mocker.patch.object(llm, 'invoke')` 失败 | ChatOpenAI 是 Pydantic frozen model | 改用 `mocker.patch('module.llm_var', mock_instance)` |
| `Send` 从节点函数返回不被 LangGraph 1.1.10 识别 | Send 只能从条件边函数返回 | 移到 `_route_supervisor()` 中构造 Send |
| 并行 fan-out 后 `next` 字段合并冲突 | `str` 类型不能合并多路写入 | 改为 `Annotated[str \| None, _last_write]` |
| `both` 链 `state["next"]` 被工具循环改写 | 工具循环中 `next` 被设为 `chem_tools` | 新增 `both_active: bool` 独立标记 |
